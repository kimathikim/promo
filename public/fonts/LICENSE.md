# Fonts

All fonts in this folder are licensed under the [SIL Open Font License 1.1](https://openfontlicense.org)
and are self-hosted, so the leaderboard makes no third-party font requests.

| File | Font | Role | Source |
|---|---|---|---|
| `newsreader.woff2` | Newsreader (variable, 200–500, Latin subset) | Display: headlines, numbers | Production Type, via Google Fonts |
| `archivo.woff2` | Archivo (variable width 62–125 %, 300–700, Latin subset) | UI: labels, buttons, body | Omnibus-Type, via Google Fonts |
| `courier-prime*.woff2` | Courier Prime 400 / 700 (Latin subset) | Mono: code, feed, prompt | Quote-Unquote Apps, via Google Fonts |

The layout and palette follow the Hermes Agent landing page (Nous Research). Hermes itself uses the
commercially licensed Sigurd and Rules families; Newsreader and Archivo are the open-licence stand-ins.
