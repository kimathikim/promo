      Join in thirty seconds

      Opt-in. Free. Open source.

      1. 01

        Get promo

        One command. Needs Python 3.7+; installs into ~/.local/bin.

        curl -fsSL https://promo-seven-virid.vercel.app/install.sh | sh
        Prefer to see every step? 
        pip install --user rich
mkdir -p ~/.local/bin
curl -fsSLo ~/.local/bin/promo https://raw.githubusercontent.com/kimathikim/promo/main/promo.py
chmod +x ~/.local/bin/promo
promo --help

        promo: command not found? Add ~/.local/bin to your PATH and open a new terminal. The installer prints the exact line for your shell.

        Hacking on it? Clone the repo and symlink promo.py into ~/.local/bin.
